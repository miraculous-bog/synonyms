# SYNONYMS — design preview

Static clickable prototype of the new SYNONYMS store (home page, product page, cart drawer).
Not the real store: prices and products come from the current catalogue, reviews and some texts are sample content.

## Publish on GitHub Pages
1. Create a repository and upload the contents of this folder (index.html at the root).
2. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`.
3. The site appears at `https://<username>.github.io/<repo>/` in 1–2 minutes.

Pages: `index.html` (home), `product.html` (Dress "Mallow"). Market switch (Ukraine / International) is in the footer.
